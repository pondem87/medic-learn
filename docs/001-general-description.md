# General description

## 1 Purpose and audience

Medic Learn provides a web and mobile foundation for learners, trainers, and staff.
The current increment establishes accounts, profile review, and communication services.
Medical educational content and course workflows have not yet been specified.

## 2 Intended outcomes

Users register with email, verify ownership, authenticate, and submit basic profiles.
Staff review profiles and manage account eligibility. Communication services deliver
opted-in welcome messages; Cognito delivers identity codes.
